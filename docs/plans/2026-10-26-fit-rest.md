# Fit Check, Rest Clearing and Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `RestOnly` chain of clearance end mills (also in the V-Carve Inlay dialog), a progress
indicator with Cancel for long computations, and a "Check Inlay Fit" command that marks collisions
and voids of the seated plug on the pocket board.

**Architecture:** Rest clearing extends `clearing.py` (swept / leftover areas for a chain of tools)
and the clearance and V-carve ops (chain order = Job order; a document observer catches deletes
and reorders). `progress.py` wraps `FreeCAD.Base.ProgressIndicator` with a `Cancelled` exception
that the ops and commands handle. The fit simulation moves from `tests/fc/fit.py` into
`vcarve_flat/fit.py`; a `Part::FeaturePython` Fit object stores the coloured marks and a path
signature.

**Tech Stack:** Python, FreeCAD 1.0.2 / 1.1.1 / 1.1.4 / 26.3rc2 (CAM, Part, Path.Area), numpy, PySide.

**Spec:** `docs/specs/2026-10-26-fit-check-rest-clearing-design.md`

### Task 5: Progress indicator with Cancel

**Files:**
- Create: `vcarve_flat/progress.py`

  (`_InlayCommand`)
- Test: `tests/fc/test_progress.py`, `tests/fc/test_inlay.py`, `tests/gui/check_gui.py`

**Interfaces:**
- Produces:
  - `class Cancelled(Exception)`.
  - `progress.task(text: str)` — context manager; the outermost one starts
    `App.Base.ProgressIndicator` (`start(text, 0)`), nested ones share it; yields nothing.
  - `progress.step()` — calls `next(True)` on the active indicator (no-op without one); FreeCAD's
    abort (`RuntimeError` from `next`) sets a module flag and raises `Cancelled`; while the flag is
    set, every `step()` raises `Cancelled` until the outermost `task` exits.
  - `progress.cancelled() -> bool` — the flag, for callers after a `doc.recompute()` (which
    swallows exceptions per object).
  - The outermost `task` exit clears the flag and calls `stop()`.
- Behaviour: the ops call `step()` per region and level (V-carve, plug through inheritance,
  clearance) and around the Voronoi / Path.Area calls of a region; on `Cancelled` an op logs
  "<label>: cancelled", leaves `commandlist` empty and re-raises, so FreeCAD marks it as failed.
  `_InlayCommand.Activated` wraps `create_inlay` in `task("V-Carve Inlay")` and, when
  `cancelled()` is true afterwards (or `Cancelled` was raised), aborts the transaction,
  recomputes and logs "V-Carve Inlay cancelled" (no popup).
- First step of implementation: in the GUI (`check_gui.py`), verify on all four builds that
  `ProgressIndicator.next(True)` processes events and that a programmatic abort is possible to
  test (e.g. `Gui.getMainWindow()`'s progress bar / `Base.SequencerBase` abort via sending Esc);
  if an abort cannot be triggered offscreen, the GUI check only asserts the bar runs and cancel is
  tested headless by patching `next` to raise `RuntimeError("abort progress indicator")`.
  Also check whether `doc.recompute()` already holds FreeCAD's own sequencer (then `task` must
  still call `next` so events flow; a nested `start` is ignored by FreeCAD).

### Task 6: Fit simulation in the package

**Files:**
- Create: `vcarve_flat/fit.py` (moved from `tests/fc/fit.py`: `PIECE`, `g1_segments`,
  `op_paths`, `tool_profile`, `_lowest`, `cut_height`)
- Modify: `tests/fc/fit.py` (keeps `make_inlay`, `seated`, imports the rest from the package)
- Test: `tests/fc/test_fit.py`

**Interfaces:**
- Consumes: `op_vcarve.clearance_ops`, the plug op's `_design` / `_bounds`, `progress.step`.
- Produces:
  - `fit.check(plug, grid=0.25, tol=0.02) -> FitResult` with
    `FitResult(points: ndarray (N,2) board XY, gap: ndarray (N,), z: ndarray (N,), collisions:
    ndarray bool, voids: ndarray bool, worst_collision: float, worst_void: float, ops: list,
    error: str | None)`.
  - Uses `plug.PocketOp` (the pocket's V-carve op) and both Jobs' active clearance ops
    (`clearance_ops`). Points: a `grid` lattice over the plug's bound (`_bounds`), mirrored back to
    board coordinates with the plug's mirror centre; only board points whose mirror lies inside the
    bound. Gap as `seated`: `(-P + G + s(q')) - z_pocket(q)`, `P` = pocket `FlatDepth`, `G` = plug
    `GlueGap`. Collisions: `gap < -tol`. Voids: `z < -1e-3` (in the pocket) and
    `gap > G + max(tol, 0.1)`.
  - `error` is set (and nothing simulated) when an op has no G1 moves or is in an error state:
    "<op label>: no toolpath, recompute it first".
  - `fit.signature(ops) -> str` — sha1 over each op's `Name` and `Path.toGCode()`.
  - `check` calls `progress.step()` per chunk of points.
